# MSCE LIBRARY

Free past papers, study guides and high-yield topics for Malawi secondary school students preparing for MANEB MSCE exams.

## Features
- Colourful, student-friendly design
- Subjects clearly separated into **Sciences** and **Humanities**
- Past papers organised by subject (not randomised)
- Unmissable / frequently examined topics highlighted
- Links to free collections (primarily FiloKin Edu)

## Deploy
This is a static site. Connect the repository to Vercel for automatic deployment.
